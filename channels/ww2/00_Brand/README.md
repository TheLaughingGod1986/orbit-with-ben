# Brand

The channel's look: logo, colours, type, the thumbnail style and channel kit. Text, manifests, builder scripts and small
vector `.svg` files live here in git; binary images (`.png`, `.jpg`) and video live on the NAS (`/Volumes/data/studio-live/ww2/00_Brand/Channel-Kit/`) and in `WW2 UAT/00_Channel-Kit/`.

- `LAUNCH_PLAN.md` — three verified channel name options, first ten topics and pilot outlines (`J2989`).
- `PLAYBOOK.md` — launch burst, packaging lab, playlists, 48-hour reads and YPP sprint (`J2990`).
- `Channel-Kit/CHANNEL_KIT.md` — ready-to-upload profile pictures (`800×800`), banners (`2560×1440` inside `1546×423` safe area), search-led channel descriptions, About links and Ben's setup checklist (`J2999`).
- `Channel-Kit/UPLOAD_TEMPLATE.md` — default upload description layout, `Education` category & `en-GB` Studio defaults, tags policy and when to tick YouTube's Altered Content box (`J2999`).
- `svg/` & `tools/build_channel_kit.py` — vector marks, YouTube safe-area SVG guide and deterministic `£0` channel art builder (`J2999`).
