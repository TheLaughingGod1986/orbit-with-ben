# Orbit Shorts — Related video pill only (locked 28 Aug 2026 · UAT 31 Aug)

**Every Orbit Short** (live, scheduled, and past public) must have a YouTube Studio **Related video** set in **desktop Studio** (not mobile). That SEA-style play-pill under the handle is the **primary / only Short → long CTA**.

Week / thumb / overlay scoring detail: `00_Brand/Channel-Setup/ORBIT_HOUSE_AND_UAT_BIBLE.md`.

## Do this

1. In **desktop** YouTube Studio: Content → Short → **Related video** → that Short’s / that week’s Thursday long → **Save**.
2. Related target is **that week’s Thursday long only** — never another Short, never a different week’s film, never a dead id, never dump every Short onto one film, never `/go/`.
3. On-screen CTA + description still name the film / parent long URL (**zero `/go/`** on Shorts). Related is the Studio funnel control; a pin is **not** a substitute and is **not required** when Related is set.
4. Requires **Advanced features** (the card exists on this channel). Data API cannot set Related — Studio finish only. Longs do **not** get this field.

## Do not (new Shorts)

- Do **not** add pinned comments on new Shorts.
- Do **not** use a pin instead of Related.
- Do **not** point Related at another Short.
- Do **not** put `/go/` on Shorts.
- Do **not** fake a Europa pill on a leftover.
- Do **not** change dates while saving thumbs.
- Do **not** remint to chase the public Shorts-player overlay when Studio Related is already correct.

## Long-form pins (unchanged)

Long-form videos still get pins (detail, `/go/`, book). Do **not** remove those.  
Long thumbs stay **picture + short SEA-style / HOTU white-on-black hook** (no Orbit · no generic CTA).

## Existing Short pins (grandfather)

Existing Short pins already live may stay. Do **not** mass-unpin. Do **not** remint to “fix” pins. Pin is **not required** when Related is set.
